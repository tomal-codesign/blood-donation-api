🚀 HOW TO START (3 STEPS - 5 MINUTES)

Step 1: Configure
────────────────
1. Go to https://app.supabase.com
2. Copy your Project URL
3. Copy your Service Role Secret
4. Edit .env file:

   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_KEY=your-service-key-here
   JWT_SECRET=your-secret
   PORT=5000

Step 2: Database
────────────────
1. Open Supabase → SQL Editor
2. Create new query
3. Copy entire DATABASE_SCHEMA.sql file
4. Paste into SQL Editor
5. Click RUN
6. In Replication: enable blood_requests & blood_inventory

Step 3: Run
──────────
1. Open terminal in project directory
2. Run: npm run dev
3. See: ✅ Server running on http://localhost:5000
4. Test: curl http://localhost:5000/health

✅ DONE! Your API is running!

🧠 AI FEATURES

1. Smart Donor Matching
   • Searches nearby eligible donors
   • Scores 0-100 based on:
     - Blood group compatibility (40 pts)
     - Distance from hospital (30 pts)
     - Last donation eligibility (20 pts)
     - Current availability (10 pts)
   • Returns top 10 ranked matches
   • Uses Haversine distance formula

2. Blood Shortage Prediction
   • Analyzes 30-day usage patterns
   • Monitors all 8 blood groups
   • Predicts days until shortage
   • Recommends donation campaigns
   • Status: critical/low/stable

3. Emergency Priority Auto-Classification
   • Analyzes patient condition
   • Considers units needed
   • Auto-sets critical priority
   • Triggers emergency alerts
