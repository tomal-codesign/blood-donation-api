✨ KEY FEATURES INCLUDED

✅ Authentication System
   - Email/password registration
   - JWT token login
   - 4 user roles (donor, patient, hospital, admin)

✅ Blood Request Management
   - Create, read, update blood requests
   - Priority classification (critical/moderate/normal)
   - Status tracking (pending/matched/fulfilled/cancelled)

✅ AI Donor Matching
   - Scores donors 0-100 based on:
     • Blood group compatibility
     • Geographic distance
     • Donation eligibility
     • Availability status
   - Returns top 10 matches

✅ Blood Shortage Prediction
   - Analyzes 30-day usage patterns
   - Predicts blood group shortages
   - Recommends donation campaigns
   - Status: critical/low/stable
