🧠 AI FEATURES IMPLEMENTED

1. Smart Donor Matching Algorithm
   • Scoring system: 0-100 points
   • Blood group compatibility (40 pts)
   • Distance/Proximity (30 pts)
   • Last donation eligibility (20 pts)
   • Availability status (10 pts)
   • Returns: Top 10 matching donors ranked by score

2. Blood Shortage Prediction
   • Analyzes: 30-day usage patterns
   • Monitors: All 8 blood groups
   • Predicts: Days until shortage per group
   • Recommends: Donation campaigns
   • Status levels: Critical, Low, Stable

3. Emergency Priority Classification
   • Auto-classifies based on:
     - Patient condition (Surgery, Accident)
     - Units needed (≥4 = critical)
     - Time urgency
   • Priority levels: Critical, Moderate, Normal

🚀 QUICK START (3 STEPS)

Step 1: Configure Environment (1 minute)
────────────────────────────────────────
1. Get Supabase keys from: https://app.supabase.com
   • Go to Project Settings → API Keys
   • Copy Project URL
   • Copy Service Role Secret

2. Edit .env file:
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_KEY=your-service-key
   JWT_SECRET=your-secret
   PORT=5000

Step 2: Setup Database (3 minutes)
──────────────────────────────────
1. Open Supabase dashboard → SQL Editor
2. Create new query
3. Copy entire DATABASE_SCHEMA.sql file
4. Paste into SQL Editor
5. Click Run
6. Wait for "Success" message

7. Enable Realtime:
   • Go to Replication section
   • Toggle ON: blood_requests
   • Toggle ON: blood_inventory

Step 3: Start Server (1 minute)
───────────────────────────────
1. Open terminal in project directory
2. Run: npm run dev
3. Wait for message: "✅ Server running on http://localhost:5000"
4. Open browser: http://localhost:5000/health
5. Should see: {"status":"ok"}
